**R2:min=-40,max=70**

**R4:0.5mA under the condition of 4.5V of Vs and a resistance of 1000Ω**

**R5:if the variance of the voltage is not very large ,the current will not change because the circuit can only use alternating current if it need to export sound with well equality, the "C" in the current is used to obstruct the direct current and ensure the alternating current to pass, it can handle the small flow in voltage and keep the current from changing.**

**R6:0.1**

**R7:40mA,105Ω**

**R8:the"leakage current"is the mere current between the pins while the pin is sealed.The leackage current of the pin in the datasheet is  **1.0 µA****
